# 페이크 뉴스 30초 「내일 전국 학교 휴교」

가상 채널 「뉴스나우 24」. 실제 방송사·기관·인물 없음. 마지막 리빌 카드 「이 뉴스는 AI가 30초 만에 만들었습니다」.

| # | 초 | 장면 | 대사·자막 |
|---|---|---|---|
| 1 | 0~6 | 스튜디오, 앵커 속보 | 「내일 전국 모든 학교가 휴교합니다. 밤사이 기록적인 폭설이 예보됐기 때문입니다」 + 속보 띠·티커 |
| 2 | 6~10 | 교실, 학생들 환호 | 「내일 학교 안 가!」 |
| 3 | 10~14 | 거실, 엄마 회사에 전화 | 「부장님, 저 내일 연차 쓸게요」 |
| 4 | 14~18 | 학원 문에 종이 붙이는 원장 | 「휴교면 휴강이지, 뭐」 |
| 5 | 18~22 | 폰 단톡방, 캡처 무한 전달 | 자막 「3분 만에 12만 명에게 전달」 |
| 6 | 22~26 | 다음 날 텅 빈 교실, 선생님 혼자 | 「…휴교 아닌데」 |
| 7 | 26~30 | 앵커 화면 글리치 | 「이 뉴스는… 가짜입니다」 → 리빌 카드 |

## 만드는 법
1. `gen_images.py` : 앵커 시트 + 샷 스틸 7장 (OpenRouter, Gemini 3 Pro Image; 샷 1·7에 앵커 참조 첨부)
2. 스틸을 이 레포(main)에 푸시 → GitHub raw URL
3. `make_video.py` : OpenRouter 영상 API, Veo 3.1 lite 720p, 스틸을 첫 프레임으로 image-to-video, 한국어 대사 생성 → 뉴스 그래픽(Pillow)·자막·리빌 카드 overlay → `out/fake_news_30s.mp4`

비용: 영상 7샷 약 $1.7 (샷 1은 필터로 한 번 재시도), 이미지 8장 약 $1.
